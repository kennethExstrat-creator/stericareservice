# SteriCare QC: Onsite Inspection Forms (reference)

Source files: "Onsite inspection format - SG.docx", "- EG.docx", "- Safedon EG.docx" (author KK Ngan). Raw files are kept in `~/Documents/SteriCare Files/Raw/QC/Templates/`.

## Common to all three
- PO / Shipment info: Manufacturer, PO/SO No., Product, Lot No., Mfg/Exp, Glove Type, Packing Mode
- Inspected by: Name, Date
- Sampling plan by size
- Watertight (WTT) and Visual (Major / Minor defect) tally tables

## Differences
| | SG (sterile surgical) | EG (examination) | Safedon EG |
|---|---|---|---|
| Last modified | Nov 2025 | Sep 2026 | Sep 2026 (cloned from EG) |
| Sizes on form | 8 | 5 | 5 |
| Sampling units | Case / Inner Box / Pouches / Gloves | Case / Inner / Gloves | Same as EG |
| Extra sampling | Pouches for dye leak test | Inner boxes for dispensing test | Same as EG |
| WTT / Visual | Each size split R / L hand | No hand split | Same as EG |
| Dispensing section | None | Generic table: Box No., Layering %, Dispensing %, Stickiness, Others (51 rows) | Safedon sheet: 6 defined defects (No cuff, Finger out, Multiple gloves out, Glove stuck, Sticky glove, Faulty cuff) x 13 boxes, 3 size blocks, Spec/Requirement + Conclusion |

## Gaps (all three)
- Dimension, FAB and dye leak samples are planned but have no results tables
- No AQL level, accept/reject numbers, overall verdict or sign-off
- Safedon dispensing sheet is a pasted image (EMF), not fillable in Word
